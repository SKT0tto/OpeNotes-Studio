> - `t001.jpg … t186.jpg`：每秒 1 帧，`tNNN` ≈ 第 NNN−1 秒；

> 测量须知：
> 1. 录屏是手机竖握横屏，分辨率 **1920×890（2.16:1）**，左上角“UP 主水印”不是游戏 UI。

> 3. 文件无音轨（B 站 DASH 视频流），音频节奏只能从口型、自动推进间隔反推（§8）。

## 2. 背景、景深、色调

- **建立镜头**：无人物，背景 1.0× 清晰（t039，`crops/blur_compare.png` 左）。
- **有人物时背景同步放大并虚化**：MCU/双人背景放大 ≈1.45×，轻虚化（高斯 σ≈2–3 px@1080，主要是放大柔化）；CU 背景 ≥2.5×，σ≈10–14 px；ECU σ≈16–20 px（`crops/blur_compare.png` 中/右）。人物放大倍率大于背景（视差，背景指数约 0.65–0.85，与我们现有 0.85 一致）。
- 映射到我们的 `dof 0..6`（半径表 0.75/2.25/3.75/5.5/7.75/9.75/12）：空镜 0；群像/双人 2；MCU 2–3；CU 5；ECU 6；暗场景（走廊）双人可到 3–4（t004）。
- **人物几乎不随环境变暗**：暗走廊背景均值 #191716，白发角色头发均值 #E5E4E5，而明亮休息室中为 #FAF8FA（仅 −8%）。即人物乘色 ≈0.92、不加色偏，靠背景暗/虚形成强主体对比。
- 听者**不压暗**（非说话者亮度与说话者相同，t051、t094）。

## 3. 镜头运动与剪辑节奏

- 镜头内**基本静止**；运动只在两种情况出现：
  1. **入场重构图**：新角色入场时相机横移/拉开，把单人构图变成双人/三人，时长 0.6–1.0 s、ease-out，平移量 0.15–0.25H（`trans/e.jpg` 46.4 s，`trans/k.jpg` 90.6 s）。
  2. **缓慢漂移**：个别反应镜头有 ≤0.03H 的横向漂移（`trans/b.jpg` 23.7–25.4 s）。
- 无推拉变焦、无抖动、无快速摇镜。
- 节奏：28 个镜头 / 约 172 s → **平均 6.1 s/镜，中位约 5.5 s**；约 42 句台词 → **4.1 s/句，约 1.5 句/镜**。最长连续镜头 21.5 s（双人对话，靠表情/动作变化维持）。
- 单人镜头约 3/4 时间给**说话者**，其余是**听者反应**或**画外音**（说话者不在画面内，名字牌显示“某某的声音”样式，sheet02 0:17–0:21）。

## 4. 人物表演

- **入场**：整体透明度 0→1，**0.2 s**（6 帧@30fps），同时从入场侧滑入 0.03–0.05H；对话框与文字同时出现（`trans/d.jpg` 40.4 s、`trans/a.jpg` 10.8 s）。
- **退场**：透明度 1→0，**0.25 s**，无位移；对话框同时隐藏（`trans/b.jpg` 21.6 s）。
- **空景节拍**：“有人来了”类桥段 = 角色淡出 → 空背景停 1.5–2.0 s（对话框隐藏）→ 新角色淡入（`trans/a.jpg`、`trans/b.jpg`）。
- **无声节拍**：对话框隐藏 1.5–2 s，只看人物反应（23.7–25.4 s、111.9–113.5 s 三人沉思）。
- **姿势随句切换**：几乎每 1–2 句换一次手部动作（手按胸、托腮、手贴脸、双手合握），切换是 Live2D motion 过渡约 0.3–0.5 s（sheet06 1:24→1:29）。
- **表情在句首切换**，偶尔句中再切（闭眼笑→睁眼，sheet01 0:12–0:15）；眨眼约每 3–5 s。
- **口型**：说话期间嘴部开合与语音同步（sheet07 1:41–1:45），文字打完后若语音未完嘴仍在动。
- **视线**：双人互看（3/4 侧向对方）；单人镜头看向画外对手方向，视线侧留白；群像时听者看说话者。
- 多人同时说（如齐声沉默）名字牌用“A & B & C”连写（sheet08 1:54）。

## 6. 情绪特效

1. **不安暗角**（t125，122.8–127.4 s）：烟雾状不规则暗角覆盖边缘约 15% W，边缘遮暗约 80%；整体去饱和 30–40%；人物加 4–8 px 白色柔光描边；轻微色差。
2. **回忆/情绪高光**（t129–t156，127.4–154.8 s）：ECU + **荷兰角倾斜 ±8–12°**（每个镜头方向交替）+ 泛光/雾化（黑位抬升约 +15%）+ **色差 RGB 分离 3–8 px@1080，向画面边缘增强**。整段 27 s 用 4 个倾斜 ECU 硬切。
3. **插入镜头**：身体局部（双手）特写，配“疑问”类短句（t163）。

## 7. UI 规格（1920×1080 换算）

### 7.1 对话区（无边框，底部渐变）
- **没有对话框边框、没有圆角面板、没有彩色名字牌**。底部是一条全宽深紫渐变：y=0.70H（756 px）透明 → y≥0.83H（896 px）满强度，到底边。叠加色 **#1A1030，最大不透明度约 0.75**（暗底实测 #252525→#1E1729，亮底→#312A3A）。
- **名字**：白色 #FFFFFF，常规字重（非粗体），字号约 **32 px**，左对齐于 x≈426 px（中心 −0.494H），基线约 y=835 px。
- **分隔线**：名字下方 y=0.784H（847 px），2 px，色 **#A2B6CE**，从 x≈414 px 起，向右在约 +0.4…+0.5H（1390–1500 px）处渐隐为透明。
- **正文**：白色，常规字重，字号约 **34 px**，行距约 **45 px**，首行顶 y≈881 px，最多 2 行；左对齐与名字同列；淡阴影（约 0 1px 2px rgba(0,0,0,.5)）。字体为无衬线中文黑体（思源黑体/Noto Sans CJK 观感）。
- **内心独白**：同一样式，正文用全角括号包裹，名字仍显示角色名（t125、t007）。
- **画外音**：名字显示“某角色的声音”样式（不改颜色）。
- 无“▼”翻页图标。右下 x≈1651 px、y≈1001 px 有 **自动播放图标**（两段弧形箭头组成的圆，直径约 53 px，白色约 80% 不透明，自动模式下持续旋转）。
- **逐字速度 ≈10 字/秒（100 ms/字）**，标点不额外停顿（`trans/d.jpg` 40.9–41.9 s、`trans/a.jpg`）。
- 无人说话的空镜、无声节拍、换场时，对话区整体隐藏（含渐变）。

### 7.2 顶部
- 只有右上一个**圆形菜单按钮**：直径约 0.10H（≈108 px@1080；桌面端可用 88–96 px），中心距右边 0.135H、距上边 0.064H；填充 #4B5382→#555E9F 竖向渐变，白色三横线图标，外圈 2 px 浅色描边（#8A93C8 左右）。Auto/Log/Skip 等收在菜单里，不常驻。

### 7.3 地点标题条（换场后）
- 在建立镜头上，**渐亮完成后约 0.9 s** 出现；居中横条，y=0.472–0.526H（510–568 px，高约 58 px），**中心 0.5H**。
- 条带蓝色 **#7F9BEA 左右，约 0.75 不透明**（亮底实测 #8799E5 / #9DBDE0），中段 ±0.4H 实色，向两侧到 ±0.6H 线性渐隐。
- 文字白色约 32 px，1–2 px 深色描边 #2A2E45 + 轻投影，居中。
- 动画：从右侧 +40 px 滑入并淡入 0.25 s → 停留约 1.9 s → 向左滑出并淡出 0.2 s；退出后约 0.5 s 第一个角色入场（`trans/banner.png`）。

### 7.4 载入卡
- 进入剧情前有一张贴纸风格四格漫画载入卡（白底图案平铺 + 白框插画，t001–t004），硬切进入第一镜。可作为可选“章节卡”。

## 8. 声音节奏（从画面反推）

- 全语音：每句时长由语音决定，约 4.1 s/句；文字 10 字/秒先于语音打完，之后保持到语音结束 + 约 0.6–1.0 s 自动推进。
- 无语音时建议的等效节奏：`句时长 = max(1.8 s, 字数 / 6.5 + 0.8 s)`（约等于人声语速 6–7 字/秒）。
- BGM/音效无法从本文件测得；建议：换场黑场期间 BGM 交叉淡变（0.8–1.2 s，与黑场同步），情绪特效段切换为另一曲或降低音量。
