OpeNotes Studio

把小说，演成一场 Live。

基于 Live2D 的 AI 剧情演出导演与制作平台。一键把小说转成《BanG Dream! Our Notes》风格的动态剧情演出——分场、选景、换装、镜头与表演由 AI 导演完成，每一句、每一帧仍由你精细手调。

FEATURES

特色

演出引擎、AI 导演与可视化编辑器三位一体：AI 负责把整部小说跑通，你负责让每一个瞬间恰到好处。

1

Our Notes 风格演出引擎

按原作演出语汇构图与剪辑：Live2D 上半身入画，中景、中近景、特写自由切换；角色真实转头、视线互看；同场景硬切、段落黑场眨眼；背景随景别放大虚化形成景深；换场时浮现地点标题条，情绪段落叠加特效。

  • 真实转头与视线
  • 硬切 / 黑场
  • 景深
  • 地点标题条
  • 情绪特效
2

AI Director

读完全文再下判断，而不是逐句瞎猜。

  • 全文拆解场景，选择背景与时间
  • 调度情绪、动作、表情、镜头与节奏
  • 服装连续性检查与合理换装
  • 演出场景的乐队站位
  • 只使用资源库中真实存在的模型、动作与背景
  • 背景按乐队标注过滤，不串场
  • 锁定的内容与你改过的内容永不被覆盖
3

可视化编辑器

资源浏览器、剧本、预览拖拽、多轨时间轴、分镜与属性面板——像剪片子一样打磨演出。

4

多 LLM，自带 Key

Claude、OpenAI 兼容接口、DeepSeek、本地 LM Studio 任选；Key 只保存在你自己的电脑上。

5

规则导演 · 无需 Key

没有 API Key 也能出片：按章节与时间词分场、按关键词匹配背景与服装、识别引号台词与说话人，并使用固定镜头节奏。产出一律标注「规则」，绝不冒充 AI。

6

项目保存与导入导出

项目保存在本机 data/ 目录；可导出为 .openotes.json 分享给他人。导出文件只记录资源 id，从不包含任何素材文件。

WORKFLOW

流程

四个乐章，一部作品。每一步都可以停下来、改一改、再继续。

  1. 01

    导入小说

    粘贴文本或打开 .txt / .md，自动识别 UTF-8 / GBK 编码与「第一章」「# 标题」等章节标题。

  2. 02

    AI 导演

    拆解场景、选背景与服装、写镜头与表演；多场并行生成，实时显示进度、调用次数与 token，可随时取消、断点续跑。

  3. 03

    手动精修

    在时间轴、分镜与属性面板里逐句调整；锁定满意的部分，只让 AI 重写一句或一个范围，并逐项审阅差异。

  4. 04

    放映 / 导出

    在内置播放器中放映，可切换 16:9 或 2.16:1 画幅并全屏，或导出项目文件与他人分享。

EDITOR

编辑器亮点：AI 起草，你来定稿

所有 AI 产出都是可审阅、可撤销、可局部重来的草稿。

资源浏览器

对外部素材库建立只读索引：模型、动作、表情、背景与音频一目了然，动作附带朝向统计。

剧本与预览拖拽

剧本逐句编辑；在预览中直接拖拽角色站位与镜头框，所见即所得。

多轨时间轴与分镜

角色、镜头、音频、特效、屏幕分轨编排，关键帧精确到每一拍；分镜视图纵览全场节奏。

锁定 · 撤销 · 局部重生成

按整句或单个字段锁定；只重生成选中的一句，或只重写镜头 / 表演 / 服装 / 站位 / 特效；一次生成即一步撤销。

AI 差异审阅

每个提议都按台词结构、镜头、表演、服装、站位、特效分组呈现前后对比，可全部接受、按范围接受或拒绝。

连续性检查

跨场景检查服装与角色状态，警告一键跳转到出问题的那一句。

AI & PRIVACY

AI 与隐私

用你的模型，留在你的电脑。OpeNotes Studio 不提供、也不经手任何 AI 服务。请求从你本机运行的服务端直接发往你选择的提供商，没有任何中转。

  • ClaudeAnthropic API
  • OpenAI 兼容vLLM 等任意兼容接口
  • DeepSeekapi.deepseek.com
  • LM Studio本地模型，文本不出本机

  • Key 只存本地

    写入本机 data/settings.local.json（已被 git 忽略），从不回传浏览器，界面只显示 sk-…087b 这样的掩码。

  • 用户自带 Key

    费用与额度由你和提供商直接结算；也可以用环境变量或 .env 提供默认配置。

  • 结果本地缓存

    按输入哈希缓存在 data/llm-cache/，同样的输入再次运行不会重复发送请求。

  • 诚实标注来源

    每一处内容都标明来自 AI、规则还是手动；未配置 AI 时，AI 入口会直接说明缺少什么，绝不假装。

HOW TO START

开始使用

需要 Node.js 22 及以上（开发使用 24）。不想用命令行？从 Releases 下载 zip，解压后双击 Start-Windows.cmd（macOS / Linux 运行 ./start.sh）即可；下面是开发者方式。

最简单：下载 zip，双击开演

从 Releases 下载最新 zip，解压后双击 Start-Windows.cmd（macOS / Linux 运行 ./start.sh）。

下载最新版 v0.1.5
1

获取代码并安装依赖

克隆仓库后安装 npm 依赖。

git clone https://github.com/SKT0tto/OpeNotes-Studio.git openotes-studio
cd openotes-studio
npm install
2

配置：Core、素材、AI

首次打开后按首页的「配置向导」三步走；也可以用配置文件。Windows 用 copy 代替 cp。

# 可选：手动指定素材库（也可在向导里一键导入你自己的素材文件夹 / zip）
cp studio.config.example.json studio.config.json
# 或使用环境变量 / .env：ASSET_ROOT、AUDIO_ROOTS、CUBISM_CORE_URL
3

启动

浏览器打开后，首页会检查素材库、Cubism Core 与 AI 配置状态。

npm run dev # 服务端 :5274，前端 :5273 —— 打开 http://127.0.0.1:5273

Live2D Cubism Core 默认在运行时从 Live2D 官方地址加载；向导里也可以一键保存一份到本机 vendor/（需确认 Live2D 许可协议）。素材不随本项目分发，请自行取得并导入。完整的图文步骤见 素材与配置教程。之后在首页点「AI 设置」填入提供商与 Key，或直接使用规则导演。

FAQ

常见问题

没找到答案？欢迎到作者的 bilibili 留言。

素材从哪里来？

本仓库不包含任何游戏素材，也不包含 Live2D Cubism Core。你需要自行准备合法获取、正确提取的素材库（models/、backgrounds/、media/），并遵守其相关条款；Cubism Core 请从 Live2D 官网获取并遵循 Live2D 的许可。素材库以只读方式使用，绝不会被复制进项目或被修改；导出的项目文件也只记录资源 id。

这是官方项目吗？

不是。OpeNotes Studio 是非官方同人项目，与 Bushiroad、Craft Egg 及其他权利方没有任何关联，也未获其认可。BanG Dream!、Our Notes 及相关角色、名称与素材均为其各自权利方所有。

我的 API Key 安全吗？

Key 只保存在你本机的 data/settings.local.json（已被 git 忽略），不会回传到浏览器，界面只显示掩码。请求由你本机运行的服务端直接发送给你选择的提供商，本项目不运营任何中转服务器。使用 LM Studio 等本地模型时，文本完全不离开你的电脑。

没有 API Key 能用吗？

可以。除 AI 功能外一切照常可用，并且可以选择「规则导演（非 AI）」：按章节与关键词分场、匹配背景与服装、识别台词与说话人。它的产出全部标注为「规则」。

采用什么许可证？

GPL-3.0-or-later。你可以自由使用、学习、修改和再分发；分发修改版时须以相同许可开源并提供源代码。素材与 Cubism Core 不在本许可范围内，适用其各自条款。

能导出视频吗？

目前提供内置播放器放映（支持 16:9 与 2.16:1 画幅）以及项目文件（.openotes.json）的导入导出，便于分享与继续编辑。
