## 2. 新阶段 P7.2 视觉还原（原作风格基线）

总原则：所有数值进入一个**可编辑的风格预设** `shared/style/ournotes.ts`（导出 `OURNOTES_STYLE` 常量 + zod schema），引擎、求解器、编译器只读预设，不得再写死常量。项目里存 `project.style`（可覆盖预设任意字段），为 P8–P10 的“全参数可调”打底。

### V1 景别表重做（`shared/staging/framing.ts`、`compile.ts`）
- 新景别集合：`establishing`（无人空镜）、`group`、`two_shot`、`mcu`（替代 bust）、`cu`、`ecu`、`insert`；保留 `medium`/`wide` 仅作兼容别名（medium→mcu，wide 含人物时报 warning 并映射为 group），迁移旧项目。
- 默认参数（全部来自 SR §1，存 style）：

| 景别 | headH | eyeY | 头顶最小留白 | 允许头顶出画 |
|---|---|---|---|---|
| group | 0.40（后排 ×0.75） | 0.32 | 0 | 是（边缘人物） |
| two_shot | 0.39 | 0.37 | 0.04 | 否 |
| mcu | 0.52 | 0.40 | 0.02 | 否 |
| cu | 0.70 | 0.43 | — | 是 |
| ecu | 0.95 | 0.42 | — | 是 |
| insert | 由目标部位框决定 | — | — | — |

- 求解目标从“头中心”改为“**眼线 y**”定位；双人脸中心目标 ±0.47H，三人 −0.50/+0.19/+0.70H（按 slot 顺序），允许身体重叠与肩部被边缘切；M1 的“非焦点人物半身”规则仅对**非 focus** 生效，focus 人物被边缘切肩是允许的。
- **验收**：unit：每种景别头高落在目标 ±8%，眼线 ±0.03H；e2e：`/play/demo` 截图与 `.verify/ref/crops/shots_grid.png` 并排对比（新增 `.verify/p72-ladder-*.png`），双人/MCU/CU 三张的人物尺寸肉眼一致。

### V2 原作风格对话区与 UI（`web/engine/DialogBox.ts`、`styles.css`、新 `web/engine/HudLayer.ts`）
- 按 SR §7.1–7.2 实现：全宽底部渐变（#1A1030，0→0.75，0.70H→0.83H）、白色名字 32 px、#A2B6CE 渐隐分隔线、34 px 正文/45 px 行距、最多 2 行、右下旋转 Auto 图标、右上圆形菜单（打开：自动/日志/跳过/隐藏 UI）。所有尺寸以 stage 高度的比例实现（容器 `--h` 变量），不是 vw。
- 子类型：独白（全角括号，自动加）、画外音（名字模板 `{name}的声音`，可改）、多人（`A & B`）。
- 旧样式保留为可选主题 `bandori-plate`（不删，供用户切换）。
- **验收**：1920×1080 截图，名字/分隔线/正文的 y 与 SR 数值误差 ≤6 px；对话区隐藏时底部无残留渐变；像素采样：黑背景下底边像素 ≈#140C24（±10）。

### V3 节奏与时长（`shared/timeline/time.ts`、settings）
- `textSpeedCps` 默认 10；新 `readingCps`（无语音时等效语速）默认 6.5；auto 时长 `max(minLine=1.8, chars/readingCps + tail=0.8)`；有语音时 `voiceLen + 0.6`。
- 编译器加“**镜头保持**”规则：同一机位默认至少覆盖 1–2 句（`minShotSeconds` 默认 4.0），除非 beat 显式指定换镜；规则导演/AI 输出也遵守。
- **验收**：demo 重写后平均 ≥3.5 s/句、≥5 s/镜；unit 覆盖 auto 时长公式。

### V4 转场与地点标题（`web/engine/Transitions.ts`、schema）
- `TransitionSchema.kind` 新增 `dip_black`（out/hold/in 三段，默认 0.2/0.2/0.25）、`scene_black`（默认 0.8/1.2/0.9，可设置“先隐藏对话区 + 停顿 0.5 s”）；`keepDialog` 选项（黑场中保留对话区）。crossfade/wipe/fade_white 保留但不在原作风格预设中使用。
- 镜头之间的转场：beat 级 `cutIn: 'cut' | 'dip_black'`（目前只有场景级 transitionIn）。
- 新 `LocationCard`：场景字段 `location?: { text, show: boolean }`，按 SR §7.3 渲染与计时；建立镜头 beat（kind=`establishing`，无人、dof 0、背景 1.0×，对话区隐藏）在换场后自动插入，时长 = 渐亮 + 0.9 + 2.35 + 0.5。
- **验收**：录 30 fps 序列，dip 总时长 0.6–0.8 s 且中间有纯黑帧；标题条 y 中心 540±6 px；seek 到标题条中段画面一致（evaluate 纯函数）。

### V5 背景与景深随景别（`compile.ts`、`BackgroundLayer.ts`）
- `shot.dof` 改为可选，缺省按 style 表：establishing 0、group/two_shot 2、mcu 2、cu 5、ecu 6；暗背景（背景平均亮度 <0.15）自动 +1（上限 6）。手动值仍覆盖。
- 人物环境乘色 `actorTint` 默认 0.92（场景级可调），听者不压暗。
- **验收**：CU 截图背景高频能量（拉普拉斯方差）< MCU 的 40%；人物像素与未乘色差 ≤10%。

### V6 表演与入退场（`compile.ts`、`Live2DActor.ts`、规则导演）
- 入场：opacity 0→1 **0.2 s** + 位置从入场侧 0.04H 滑入（同 0.2 s，outQuad）；退场 0.25 s 仅淡出。入场时若当前镜头为单人且新人物属于对话方，自动生成相机重构图 key（0.8 s outCubic）。
- 规则导演默认：说话者每句句首换表情（按 emotion），每 1–2 句换一个手势 motion（同 emotion 家族内轮换，避免连续重复），眨眼 3–5 s 随机（确定性种子），口型在“语音时长或文字显示时长”内驱动。
- 新 beat 类型：`silent`（对话区隐藏的反应节拍，默认 1.8 s）、`empty`（空景，默认 1.8 s）。
- **验收**：demo 中任一 20 s 双人段落至少 6 次 motion 变化、表情变化 ≥ 句数×0.7；入场帧序列显示 6±1 帧完成淡入。

### V7 情绪特效（新 `web/engine/fx/`）
- `vignette_anxiety`（烟雾暗角纹理 + 去饱和 0.35 + 人物白色外发光 6 px）、`memory_glow`（泛光 + 黑位抬升 0.15 + 径向色差 0–6 px）、`dutch`（相机 roll ±10°，相机 pose 加 `roll` 字段）。都是 screen/camera 轨道上的关键帧，有强度 0–1 与进出时长。
- 景别 `insert`：目标 = 角色身体部位框（hands/chest/face），由模型校准中的部位探测或手动框提供。
- **验收**：开启/关闭对照截图；roll 时视口四角仍被背景覆盖（夹紧考虑旋转外接框）。

### V8 Demo 重写 + 对照验收
- 用原作风格重写 `tests/fixtures/demo-project.json`（原创台词，约 60–90 s）：换场黑场 + 地点条、空景节拍、双人长镜头、内心独白 CU、一次不安暗角、一次倾斜 ECU、三人群像入场重构图。
- 验收产物：`.verify/p72-*` 与 `.verify/ref/` 同景别并排拼图 `p72-vs-ref-montage.png`，由验收方逐项对照 SR。
- **G11 风险验证**：先在 ActorLab 把 3 个模型渲染到 ECU（头高 0.95H），检查纹理是否糊；若糊，评估渲染分辨率倍率（renderer resolution 1.5–2）或把 ECU 上限降到 0.8 并在 style 中注明。

## 3. “人工可以调整所有功能”：P8–P10 需要暴露的参数

### 3.1 原则
1. **三层继承**：风格预设（全局）→ 场景覆盖 → beat/镜头/关键帧覆盖。每个字段在属性面板显示“来自哪一层”，可一键“恢复继承”。
2. **自动 = 可见的值**：求解器、规则导演、AI 产生的每个结果（相机位姿、motion 变体、时长、dof、入场时间）都要落成可见、可改、可锁的值，并保留 `source` 徽标（PLAN §1.1）。不存在“只能由算法决定、人改不了”的量。
3. **数值 + 直接操作双通道**：所有数值字段支持拖拽改值（scrub）、键盘输入、表达式（如 `0.4*2`）；可直接操作的（人物位置、相机框、眼线、标题条位置）在预览里有手柄。
4. **参考对照**：预览可叠加参考帧（洋葱皮，透明度可调），用于把构图对齐 `.verify/ref/` 或用户自己的截图。

### 3.3 对各阶段的具体修订
- **P8（进行中，不打断）**：仅加两件事——① store 中预留 `project.style`（P7.2 落地前可为空对象，schema 允许）；② 编辑器外壳直接采用 §4 的设计 token 与布局骨架（成本低、避免返工）。
- **P9**：属性面板改为“分组 + 可折叠 + 继承指示”的检查器（§4.3）；新增“风格预设”面板；舞台直接操作增加：相机框手柄（拖框=改 zoom/中心，旋转手柄=roll）、眼线/安全区/三分线叠加、参考帧洋葱皮。

## 4. 编辑器前端精致化设计方向

参考：DaVinci Resolve（Edit/Fusion 页）、After Effects、Premiere Pro、Live2D Cubism Editor 的暗色专业 UI。目标是“长时间使用不累眼、信息密度高、每个控件都可直接操作”。

### 4.1 布局（≥1440 px 宽为主，1280 可用）
```
┌ 顶栏 40px：项目名·保存状态 | 工作区切换(剧本/演出/分镜/预设) | 撤销重做 | 播放控制 | AI/规则按钮 | 设置 ┐
├ 左栏 280px（可折叠/可拖宽）  ┬ 中央预览（16:9，居中，暗灰底 #0B0C0F） ┬ 右检查器 320px ┤
│ 标签：剧本 / 资源 / 角色 / 场景 │ 叠加开关：安全区·三分线·眼线·参考帧 │ 分组可折叠属性 │
│                              │ 预览下方 32px 传输条：时间码 / 帧步进 │               │
├──────────────────────────────┴──────────────────────────────────────┴───────────────┤
│ 底部时间轴 260px（可拖高）：左 200px 轨道头（锁/静音/独奏/颜色）+ 右轨道区，顶部时间尺按 beat 分段 │
└ 状态栏 22px：选中对象 · 警告数 · 渲染 fps · 缓存 ───────────────────────────────────────────┘
```
- 面板之间 1 px 分隔线 + 4 px 可拖拽热区；布局存 localStorage；预设两种工作区（“演出”= 预览最大化；“剧本”= 左栏加宽）。

- 对比度：主文字/面板 ≥ 7:1，次要文字 ≥ 4.5:1。焦点环 2 px `--accent`。

### 4.3 控件与交互要求
- **数值字段**：左右拖动标签即调值（Shift 粗调 ×10、Alt 细调 ×0.1），双击输入，支持单位与表达式；右键菜单：恢复继承/锁定/复制值/粘贴值/“设为预设默认”。
- **检查器**：分组（变换/表演/镜头/文字/特效/音频），组标题右侧显示“覆盖了 N 项”；每个字段左侧 6 px 来源色条 + 锁图标；被继承的值以 `--text-2` 显示，覆盖值以 `--text-1` + 左侧色条。
- **时间轴**：J/K/L 变速播放、←/→ 逐帧、↑/↓ 跳 beat、I/O 入出点；关键帧菱形（选中填充 `--accent`，锁定灰色带锁）；框选、Shift 加选、Alt 拖动复制；吸附到 beat 边界/播放头/其他关键帧（按住 Ctrl 临时关闭）；缓动在关键帧右键或曲线编辑器中改；轨道可折叠为角色组。
- **预览**：滚轮缩放预览（不是相机）、空格按住平移；选中角色显示包围框 + 朝向手柄 + 视线手柄；选中镜头显示相机框（可拖、可缩放、可旋转）；叠加层：动作安全区 93%、标题安全区 90%、三分线、SR 眼线带（0.36–0.45H）、参考帧洋葱皮（透明度滑块、差值模式）。
- **分镜**：卡片 16:9 缩略图 + 景别徽标 + 时长 + 转场图标；多选批量改；拖拽排序。
- **反馈**：所有修改 <100 ms 反映到暂停态预览；长任务（缩略图、AI）在状态栏显示进度且不阻塞；错误/警告集中到“问题”面板，点击定位对象。
- **快捷键表**可在设置中改，`?` 打开速查；全部操作可撤销（历史面板可视化，可跳到任一步）。
- 禁止：浅色大面积背景、无单位的裸数字、只能通过 AI 修改的字段、模态对话框打断编辑（用侧滑面板/弹出层）。
