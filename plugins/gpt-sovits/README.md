# GPT-SoVITS 自动配音（插件）

用你**自己**运行的 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)，给对白自动配**日语**：AI 先把中文台词译成口语日语（按角色性格），再按每个角色的参考音频逐句合成，配音随时间轴播放，说话人的嘴随声音开合。默认关闭，不装不影响任何功能。

## 安装

1. 下载 `openotes-plugin-gpt-sovits-v<版本>.zip`。
2. 解压到 OpeNotes Studio 文件夹（得到 `plugins/gpt-sovits/plugin.json`）。
3. 重启软件。编辑器顶栏出现「配音」按钮。

## 准备 GPT-SoVITS

在 GPT-SoVITS 整合包文件夹里启动 api_v2（新建 `go-api.bat`，双击运行；端口默认 9880）：

```
runtime\python.exe -I api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

然后在编辑器里：顶栏「配音」→ 勾选「启用」→「服务地址」填 `http://127.0.0.1:9880` → 「测试连接」。

## 给角色设声线

每个角色（按角色 key 记，所有项目共用）一张卡片：

- **参考音频**（必填，GPT-SoVITS 那台电脑上的路径，3–10 秒）、**参考文本**（音频里说的话，建议填）、参考语言。没有参考音频的角色**不配音**；旁白、动作、停顿也不配音。
- **GPT 权重 / SoVITS 权重**：每个角色用自己训练的模型时填，留空则用默认权重。
- **默认 GPT / SoVITS 权重**：角色没填时用这里的。
- **串模型规则**：生成时每个角色会先把自己的权重加载进 GPT-SoVITS，之后一直用到下一个角色换掉它。所以只要有任何一个角色填了自己的权重，**所有要配音的角色都必须有权重**（自己的或默认的），否则那个角色的台词会报错「没有填权重…否则会用到上一个角色的模型」。如果大家共用 GPT-SoVITS 启动时加载的那一个模型，就让所有权重栏（含默认）都留空。
- 「试听」：合成一句固定的日语，听听声线。

### 自动匹配

只在 GPT-SoVITS 和本软件在**同一台电脑**上时可用。**只填一个「模型文件夹」就够了**，可以是：GPT-SoVITS 的安装目录（整合包根目录）、别人打包好的模型包（例如 `D:\GPT-SoVITS\MYGO-models`）、某一个角色的文件夹，或者装着几个模型包的文件夹。这个文件夹里的所有子文件夹（最深 5 层）都会被读到；可以直接粘贴 Windows「复制为路径」得到的带引号路径，首尾的引号（直引号、弯引号）和空格会自动去掉（所有路径栏都是）。「其他模型 / 参考音频文件夹」是可选的，每行一个，模型文件夹留空时只填它也能用。

点「自动匹配」后：

- 读 `.ckpt` / `.pth` 权重和 wav / mp3 / flac / ogg 参考音频（mp3 也读时长）。安装目录里的 `GPT_weights*/`、`SoVITS_weights*/`（记下版本，如 v2Pro）和 `ref*/`、`参考音频*/` 最先读，其余按模型包处理。`pretrained_models`、`runtime`、`tools`、`logs`、`output` 这类大文件夹和 RVC 变声模型（文件夹名含 `rvc`，也是 `.pth`）会跳过；每个文件夹各有自己的文件数上限，大安装目录不会挤掉旁边的模型包。路径不存在或不是文件夹会给出提示，不会悄悄忽略；什么都没找到时会告诉你读了哪些文件夹、各有多少 `.ckpt` / `.pth` / 音频，以及该怎么办。
- **谁的文件**：先看所在的文件夹名（`长崎素世/…`），再看文件名；对照的是**所有已知角色**，不只是当前项目的。所以放在别人文件夹里的文件，即使文件名里提到你项目里的角色（例如台词里有「愛音」），也不会算到她头上；包里项目之外的角色会另外列出。**台词一样的长文件名从不决定归属**，只有 `tomori_01.wav`、`愛音.wav` 这种简短的标签式文件名可以。名字认中文名、日文汉字（燈・愛・楽・豊…）、罗马字、假名，会去掉 `_e15`、`_s200`、版本号等训练标记。
- **选模型**：同一次训练的 GPT 与 SoVITS 按文件名前缀配对（`soyo-e10.ckpt` 配 `soyo_e8_s…pth`），默认选朴素的前缀（不选 `soyo非夹` 这类变体），再取 epoch 最高的；模型版本读 SoVITS 文件头（`04` = v4）。其他版本在核对表的下拉框里。
- **选参考音频**：只考虑 3–10 秒的（GPT-SoVITS 会拒绝范围外的，所有版本都一样），范围外的直接排除。平静叙述的优先（`叙述`、`平静`、`通常`、`普通`、`标准`；`交流`、`叙述，提示` 这类稍后），带强烈情绪或特殊语气的标签（颤颤巍巍、兴奋、悲伤、惊慌、生气、哈 …）、没有标签却满是 `……` 的停顿、以省略号开头、带感叹号或问号的文本都会扣分；文本来自 `训练v4…` 文件夹（干净的人工校对）比 `训练v2…`（粗糙的语音识别）可靠，文本里夹着字母、数字或断开的空格这类多半是识别错误的也会扣分；`夹子音`、`不演了`、`不夹` 这类声线变体排在后面。长度 4–6.5 秒最优先，其余条件相同时取更短的文本。不写死任何角色或台词。
- 参考文本：同名 `.txt` / `.lab`，或 GPT-SoVITS 的 `.list`（`路径|说话人|语言|文本`），或文件名本身（去掉【开心】这类情绪标签、`叙述` 这类开头的中文情绪词与扩展名；开头剩下一段没认出、带简体字的，视为文字不可靠）。
- 文件名对不上的项目角色，如果配置了 AI，会再请 AI 在「没有任何名字的文件」里按 BanG Dream! 知识匹配一次（它给的路径必须是扫描到的文件）。

结果是一张**可以编辑的核对表**：包里找到的每个角色一张卡片，项目里的角色默认勾选，项目之外的不勾（声线各个项目共用，需要的话勾上）。每张卡片可以换**模型**（下拉框：`soyo` / `soyo非夹`，GPT 与 SoVITS 配好对），换**参考音频**（下拉框：平静的排前面，显示情绪标签、秒数、文本）并点「试听」听那段参考音频（只能播最近一次扫描到的文件夹里的音频），也可以直接改**参考文本**。点「**应用并保存**」会把勾选的角色声线和文件夹设置**一起保存**，面板里显示保存了哪些角色；关闭面板时如果还有没保存的改动会先保存，保存失败则不关闭并显示原因，不会悄悄丢掉。

## 生成配音

「配音」面板里 **生成整个项目的配音 / 生成当前场景**，或在检查器里选中一句台词点 **生成这一句配音**。过程：

1. AI（你在「AI 设置」里配好的那个）把需要配音的台词译成口语日语，存在台词上，检查器的「日语台词」里可以直接改（改过的不会被重新翻译覆盖）。
   角色之间的称呼（爱音叫灯「ともりん」等）和第一人称按 `shared/data/addressing.json` 这张表来，AI 译完后程序会再校正一遍（手改过的日语不动）；表里没列的组合交给 AI 按原作判断。
2. 按角色逐句调用 GPT-SoVITS 合成，音频存到 `data/projects/<项目>/voice/`。已有且内容没变的句子会直接用现成的那一版，不会重新合成。
3. 结果作为**一步操作**写进项目，可以撤销。有进度条，可以取消。
4. 台词时长自动延长到至少「配音时长 + 句尾留白」（固定时长的台词也一样，不会把声音截掉）。台词文字改了，旧配音不再使用，需要重新生成。

### 漏字检查与自动重试

GPT-SoVITS 偶尔会在句子中间提前结束（漏掉后半句）。每合成一遍，插件都会检查：找出声音第一次和最后一次超过 -35 dB（相对这一段最响处）的位置，算出有声部分的秒数，再按日语估算的音拍数（假名 1、小写假名 0、汉字 1.8、标点不算）折算；每个音拍不到 0.125 秒（语速调快时按比例放宽）就当作疑似漏字，换一个新的随机种子重来，**最多重试 2 次**，保留有声部分最长的一遍。音拍数少于 6 的短句（`はい`、`うん`）估算不可靠，不检查。进度里会写「疑似漏字，重试第 N 次」，结束时写重试了多少次；重试后仍然偏短的句子会保留最长的一遍，并在面板的结果里和检查器里标出「可能没读完」，请听一遍，不对就点「重新合成」。

### 不会覆盖，不会丢

- **每一遍合成都用新文件名**（`<句子>-<内容哈希>-<随机种子>.wav`，种子会存下来，可以复现这一遍）。重新合成、「全部重新合成」都不会改写旧文件，所以撤销真的回到上一遍的声音；旧格式（文件名里没有种子）的文件照样能读、能用。
- 每句最多保留最近 5 遍，另外正在用的那一遍永远保留。
- **取消或失败不会清掉已有的配音**：只有这次真正做完的句子才换成新的声音，没做完的（取消、GPT-SoVITS 连不上、中途出错）保持原来的配音；只有新翻译、没来得及合成的句子，会存下新的日语，但仍然保留原来那段（它对应的中文台词没变）下的配音，下次生成时会按新日语重新合成。进度和结束提示只数真正做完的句数（「已完成 3 句」）。

同一句日语每次合成的语气都略有不同：检查器里的 **重新合成** 用同一句日语再合成一版，**重新翻译并合成** 结合上下文重新翻译这一句再合成（手改过的日语要确认才会覆盖）。新版本生成后会自动播放一次，一步撤销就回到上一版。

### 播放时点击

有配音的台词：文字还在打字时，点击（点「下一句」或画面）只是把文字显示完整，声音和时间照常往下走；文字显示完后再点，才进入下一句并停掉这句的声音。没有配音的台词和以前完全一样。

播放音量在面板里调（浏览器记住）。导出项目文件时只带日语文本，不带音频。

`data/plugins/gpt-sovits/settings.json`（旧版本的 `data/voice.local.json` 会被自动读取）。
